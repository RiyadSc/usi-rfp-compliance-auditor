## Rules

1. Prefer a named class from `globals.css` over one-off hex or cleared palette utilities.
2. Status always includes glyph or text, never colour alone.
3. Coral (`critical-*`) only for blockers, conflicts, destructive actions, failures.
4. Serif (`display-accent`) only for rare editorial moments.
