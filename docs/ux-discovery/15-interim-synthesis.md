## Executive summary

The RFP Compliance Auditor is a strong **evidence-gated, multi-axis decision-support architecture** with a recently improved presentation layer. The core UX problem is not visual polish. It is whether users can **orient, judge, resume, and avoid false certainty** without reconstructing state across object pages or misunderstanding readiness language.

Proxy/stakeholder diagnosis says:

1. **Keep** separate support / precedence / proof / workflow / human axes.
2. **Re-open** opportunity-centered IA as a hypothesis, not a settled truth.
3. **Prioritize** judgment spine, change/resume, addendum impact, and trust calibration over further chrome.
4. **Do not implement** major structural changes until Phase G validation and §65 gates.
