# Parallel Operating Cadence

**Date:** 2026-07-25  
**Authorization:** CEO — begin UX work within guardrails; discovery and implementation progress together.

```text
Track 1 — Session 0 (USI Demo)
  → Collect stakeholder observations (labeled grades)
  → Request Sessions 1–4

Track 2 — UX implementation (safe changes)
  → Only changes that pass the implementation filter + three questions

Track 3 — UX research
  → Contextual inquiry → validation → refinement

Track 4 — Product evolution
  → Engineering → testing → deployment
```

Tracks run **in parallel**. The UX lead does not sit idle waiting for interviews.

---

## Three questions (every change)

1. **Which user decision does this improve?** (Decision ID from `24-…`)
2. **What evidence supports making this change?** (friction ID, hierarchy gap, Session note, invariant)
3. **How will we know it actually improved the experience?** (resume probe, comprehension, task metric)

If any answer is missing → **not ready**.

---

## Hold list (Track 3 / Session 1+ before shipping)

Do **not** fundamentally change yet:

- Global or opportunity **navigation** structure
- **Information architecture** / primary destinations
- **Object hierarchy**
- **Opportunity lifecycle** model
- **Primary workflows** / nine-step as authority
- **Mental model** replacements
- **Major dashboards** redesign

These wait for observing real proposal professionals.
